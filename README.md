# ai-assingment
One of the main benefits I saw in using AI for this assignment is that I was able to generate all the code to write this entire notebook in the span of a few minutes. Of course, for really experienced Python coders, this would be no problem at all, but for me it takes a lot longer to write all the code for this, so the fact that I could have everything working just like that was very nice and allowed me to be more efficient with my time. AI is also growing smarter and smarter by the day and so I have a lot of confidence that the code it produced was reliable and completed what I asked it to do. Of course, the real danger lies in trusting AI too much and allowing it to do everything for you. There were multiple times where what it outputted was not what I had intended it to. Some of those were my fault in not being direct enough in my prompts, but also some of it was just the AI doing it a different way that was not intended. 
It is dangerous for humans to just feed queries into a AI engine and blindly trust that it would output what is desired. There needs to be a certain layer of double checking and making sure that the code is actually what is desired for the project or dataset, and sometimes when AI is just blindly trusted this does not go to plan. For example, when I tried to download the .csv file, for some reason my jupyter notebook was in a different directory and so I had to change that manually in jupyter. However, Gemini did not know that and so it kept outputting code that I could not use because my csv file was not being read. Another example of this is forgetting the name that it gave my cleaned csv file. It saved it as a different name in a later code snippet and so that code would not run in jupyter since there was no data frame with that name. So, I had to go back and manually check it to see what the issue was, which is where I found the naming error and corrected my Gemini prompt. Overall, like I said, AI is an incredible tool that I believe is being and will be used in so many ways--especially in the Data Science industry--moving forward. It is important to use this tool to our advantage while also not letting it do everything for us and not being able to correct the code it is outputting.
